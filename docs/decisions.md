- Nov 25 — Daily Call "joins tomorrow" (SPEC §6.4.1) is decided by the worker, not the app: `POST /daily-call` says `joins_tomorrow` only once the bot has a decision since 09:00 IST and still no view for the IST day; before that it says `waiting`, so a bot is not told "tomorrow" before 09:00 or while its 09:00 slot or debut is still running. - Nov 26 — `pnpm audit` exceptions for the Privy wallet tree (#71, PR #322): ws is fixed by the override `ws@>=8.0.0 <8.21.0 → ^8.21.0` (same major). Two highs are ignored through `pnpm.auditConfig.ignoreCves`. (1) CVE-2023-54404 / GHSA-mrhx-c7xc-m3w5, zod < 4.6.6, memory blow-up when parsing a huge array: no patched zod 3.x exists, and forcing zod 4 would be a major bump for @coinbase/cdp-sdk, @reown/appkit-wallet and x402, which pin zod 3. abitype only has zod as an optional peer for `abitype/zod`, which we don't import. The worst case is a user's own tab hanging, and we don't enable WalletConnect or wallet login. The worker uses zod 4.6.7. Revisit when Privy's dependencies move to zod 4 / query-string 8, and drop these ignores then — Divesh + Claude
