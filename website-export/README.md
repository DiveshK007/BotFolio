# BotFolio website export (Nov 20 2026)

- `prototype/index.html`: the working prototype. Open it in a browser. The yellow "Review states" button switches data states.
- `apps/web/`: Next.js 15 App Router pages and components, ready to drop into the repo. Typechecked and built here.
- `SITE_SPEC.md`: per-page spec. `BUILD_BRIEF.md`: build order, wiring, definition of done.
- `CLAIMS.md`: claim → source table. `OPEN_QUESTIONS.md`: gaps and the decisions taken.
- `HANDOFF_PROMPT.md`: paste into Claude Code.
- `screens/`: PNGs of every page and state (1440 and 360, light and dark). `og/`: OG cards.

All data in this export is EXAMPLE except the oracle feed addresses and chain facts (SPEC §0, verified Nov 19) and the live oracle price reader in `lib/site/data.ts`.
